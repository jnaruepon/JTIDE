**Simplify ESP32 Development**
A high-stability block-based visual programming environment designed for IoT and Robotics applications.

**Key Features**
- Full IoT Integration
Complete Anto, Blynk 1.0, Dashboard, Database (Firebase, Google Sheet, MySql), MQTT with specialized blocks for decimal data and read-on-request events.

- Robotics Ready
Includes high-level blocks for motor movement and sensor management (DHT11/22, Ultrasonic) with clear, full-text commands.
